# 合同审查风险规则库

> 本规则库为合同审查智能体（FR-07）的知识来源。**法条依据须由承办律师核对现行有效条文后采纳**，本库仅为辅助初审示例。
> 规则分三类：A 风险表述（措辞命中）｜ B 权利义务失衡 ｜ C 缺失条款。分级：高(P0 必改)/中(P1 建议改)/低(P2 提示)。

## A. 风险表述规则（命中即报）

| 命中关键词/模式 | 风险级 | 风险说明 | 修改建议 | 依据（待律师核对） |
|---|---|---|---|---|
| 概不负责 / 不承担任何责任 / 免除全部责任 | 高 | 一方完全免责，可能构成加重对方责任、排除对方主要权利的格式条款 | 明确责任范围与限额，删除"全部/任何"绝对化免责 | 《民法典》第497条（格式条款无效情形） |
| 最终解释权 / 保留最终解释权 | 高 | "最终解释权归本方"属无效格式条款，损害对方权益 | 删除；改为"双方协商或依法解释" | 《民法典》第498条 |
| 无条件 / 不可撤销地放弃 | 高 | 概括性放弃权利，可能显失公平 | 限定具体情形与范围 | 《民法典》第151条（显失公平可撤销） |
| 空白金额（____元 / XX元 / 待定 / 若干） | 高 | 关键金额未确定，履行无依据、易生争议 | 填写确定金额或明确计算方式 | 《民法典》第470条（合同内容确定） |
| 空白日期（____年 / XXXX-XX / 待定） | 高 | 关键时间未确定，履行期限不明 | 填写确定日期或约定确定方法 | 《民法典》第470条、第511条 |
| 有权单方解除 / 单方随时终止 | 中 | 单方解除权配置失衡，需审查是否对等 | 明确解除条件、通知期与对等安排 | 《民法典》第562条、第563条 |
| 有权单方变更 / 单方调整 | 中 | 单方变更条款失衡 | 变更须双方书面同意 | 《民法典》第543条 |
| 逾期利息 / 违约金（未写比例或标准） | 中 | 违约金标准缺失或过高（超过损失30%可被调整） | 明确违约金计算标准，避免过高/过低 | 《民法典》第585条 |
| 定金（超过主合同标的20%） | 中 | 定金超过20%部分不产生定金效力 | 定金比例不超过标的额20% | 《民法典》第586条 |
| 自动续约 / 自动展期（无退出机制） | 低 | 自动续约缺少退出通知机制 | 增加到期前书面通知/异议机制 | 《民法典》第510条 |
| 管辖法院为一方所在地（对方可能异议） | 低 | 协议管辖需与争议有实际联系 | 约定与争议有实际联系地的法院 | 《民事诉讼法》第35条 |

## B. 权利义务失衡规则

- 仅约定一方违约责任、未约定另一方对等责任 → 中风险，建议对等化。
- 付款义务明确但交付/质保义务模糊 → 中风险，建议明确交付标准与验收。
- 保密义务单向 → 低风险，建议双向保密。

## C. 关键缺失条款清单（缺失即报）

| 关键条款 | 缺失风险级 | 说明 |
|---|---|---|
| 违约责任 | 高 | 无违约责任，守约方救济困难 |
| 争议解决 / 管辖 | 高 | 未约定管辖或仲裁，争议解决路径不明 |
| 付款/履行期限 | 高 | 无期限约定，易生履行争议 |
| 标的 / 数量 / 质量 | 高 | 合同主要内容缺失，可能影响成立 |
| 不可抗力 | 中 | 未约定不可抗力，风险分担不明 |
| 保密条款 | 中 | 涉及商业信息时缺失保密约定 |
| 合同生效条件 | 中 | 生效时点/条件不明 |
| 通知与送达 | 低 | 未约定有效送达方式 |

## 维护说明
- 律师应按客户高频交易类型（买卖/租赁/借款/劳动/服务/股权）扩充规则。
- 每条规则的"依据"列须定期核对最新法律法规与司法解释。
